# Serge Fomin — Tattoo Artist Portfolio

Многостраничный личный сайт тату-мастера **Сергея Фомина** (sergio_fom) из Перми.

## Страницы

| Страница | Файл | Описание |
|----------|------|----------|
| Главная | `index.html` | Hero, услуги, избранные работы и эскизы |
| О мастере | `about.html` | Биография, философия, награды, стили |
| Услуги | `services.html` | Татуировки, эскизы, cover-up, лазерное удаление |
| Работы | `portfolio.html` | Галерея с фильтрами по стилям |
| Эскизы | `sketches.html` | Библиотека готовых эскизов и заказ под индивидуальный |
| Контакты | `contact.html` | Студия Tattoo EXTRA, форма записи, карта |

## Сайт онлайн

**https://andrewf250.github.io/SergioTattoo/**

> Если ссылка пока не открывается — один раз включите GitHub Pages:
> [Settings → Pages](https://github.com/AndrewF250/SergioTattoo/settings/pages) → **Build and deployment** → Source: **Deploy from a branch** → Branch: **gh-pages** / **/ (root)** → Save.

Сайт автоматически обновляется при каждом push в `main` (ветка `gh-pages`).

## Локальный запуск

```bash
python3 -m http.server 8080
```

Сайт будет доступен по адресу http://localhost:8080
